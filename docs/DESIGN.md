# Overview

熊本・山鹿の農家が畑で実地テストして書くベアフットシューズ専門メディア。
デザインの型は **LIG型の目次ポータル**（コンパクトなヒーロー → Pickup → 新着グリッド → サイドバー → 連載）に、
**エディトリアルなトーン**（明朝見出し・罫線・番号付き見出し）を重ねたもの。
信頼と読み心地が最優先。装飾で世界観を作らず、**写真（畑・泥・靴の実写）に色を語らせる**ため、地色は無彩色に徹する。

# Colors

- 60-30-10: グレー地(60) / 白い面と墨色テキスト(30) / 深緑(10)。
- 緑は「押せるもの・分類ラベル」にのみ使う。飾りとしての緑面は作らない。
- 反転セクション（accent-deep地に白文字）はメール登録ブロック1箇所のみ。
- **クリーム・ベージュ・生成りの背景は禁止**（AI生成サイトの記号になっているため。運営者の明示的な決定）。

# Typography

- 見出し: 明朝（Shippori Mincho B1）。字間 +0.02em 程度、行間 1.5〜1.7。
- 本文: ゴシック。行間 1.85〜1.95 でゆったり読ませる。
- 英字ラベル（PICKUP / LATEST / カテゴリ / 日付・実測数値）: IBM Plex Mono、小さく・字間広め。数値は tabular figures。
- 見出しは text-wrap: balance ＋ 意味の切れ目で改行。

# Layout

- トップ: sticky header → タイポ主体の全幅ヒーロー（コピー＋リード＋入門CTA1本。右端に縦書きmonoラベル）→ 写真マーキー帯 → Pickup 2枚 → 新着リスト行＋右サイドバー(320px) → 連載帯 → フッター。
  - 2026-08-14 に plan-c3-portal-typo.html で改修（旧: スプリットヒーロー＋新着2列グリッド）。理由: 写真の質に依存せずコピーで立たせる＋実写は帯にまとめて見せるため。一覧・カテゴリページの新着は2列グリッドのまま。
- サイドバー: **メール登録（緑反転）→ 著者ボックス（白面・近影・畑テストの一文）→「まずこの3本から」(記事20本超で人気ランキングに切替) → カテゴリチップ**。
  - 順序は 2026-08-08 の運営者決定で変更（旧: 著者 → 3本 → メール登録 → カテゴリ）。理由: 本命KPIがメールリスト構築であり、サイドバー最上部＝最も視認される枠をCVに充てるため。
  - **著者ボックスは内容・体裁を変更しない**（自己紹介文のまま維持）。位置のみ2番目へ移す。これも運営者決定。
  - 著者ボックスは「個人ブログの自己紹介」ではなく「一次情報の担保＝E-E-A-Tの署名」として置いている。将来トーンを見直す場合は、経歴文ではなく検証実績（検証足数・累積距離・テスト環境）を数字で見せる方向で検討する（保留案・未確定）。
- 記事ページ: 本文 680-760px の中央1カラム＋追従目次。パンくず必須。
- サブページ（プライバシー・運営者情報・問い合わせ）: 中央1カラム、番号付き明朝見出し＋上罫線で統一。
- モバイル: 1カラム縦積み、タップ領域44px以上。

# Components

- カード: 白面 or 写真 + カテゴリラベル(mono緑) + 明朝タイトル + 日付。枠線は line色1px、影は使わない（使う場合もごく薄く）。
- ボタン: 塗り(accent)がprimary。角丸2px。ホバーで accent-deep。
- 矢印: **細いロングアロー（軸長め・鏃小さめ）のSVG1種に全サイト統一**。ホバーで4px右にナッジ。
- アイコン: 実SVG（lucide系, stroke 1.5px）のみ。検索虫眼鏡・シェブロン程度に最小限。
- フォーム: 枠線型入力＋緑のフォーカスリング。ラベル上置き、任意項目にだけ「(任意)」。送信ボタンは disabled→送信中→完了 の3状態。
- 写真: 実写（畑・泥・靴）のみ。比率はカード16:10、Pickup16:9、ヒーロー4:3。ホバーで scale(1.03-1.04)。

# Motion

強度: **控えめ**。
- ホバー: リンク下線スライドイン、カード画像ズーム、矢印ナッジ。すべて ease-out 150-250ms。
- スクロール: セクションの薄いフェードアップ程度（任意）。パララックス・ピン留め・スクラブは使わない。
- 記事ページ上部に 2px のスクロール進捗バー（accent）は可。

# Do's and Don'ts

Do:
- 写真は自前の実写に差し替える（モックのWikimedia素材はレイアウト確認用）
- 実測数値・日付は mono + tabular figures で組む
- eyebrow(英字小ラベル)は PICKUP / LATEST / SERIES などセクション見出し行に限定

Don't:
- クリーム・生成り・ベージュ背景（禁止・運営者決定）
- カードや見出しの1辺だけ色付けするアクセントボーダー
- 頭文字を丸に入れた擬似アイコン（実ロゴがない項目はテキストで組む）
- 「→」「›」等の文字矢印（矢印は統一SVGのみ）
- 写真上の雰囲気キャプション（載せてよいのは出典・実測値・操作ラベルのみ）
- トップの全面写真ヒーロー（全画面写真はテストポリシーページ・連載トップ限定）
- ストックフォト的な「美しすぎる」素材の全面使用（AI感の源）
